# PSU Route Finder — ไปมหาวิทยาลัยสงขลานครินทร์ วิทยาเขตภูเก็ต

เว็บไซต์ตัวอย่างสำหรับค้นหาและเปรียบเทียบเส้นทางรถยนต์จากจุดเริ่มต้นของผู้ใช้ไปยังมหาวิทยาลัยสงขลานครินทร์ วิทยาเขตภูเก็ต

## วิธีเปิดใช้งาน

1. ดาวน์โหลดและแตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `psu-phuket-travel-web` ด้วย Visual Studio Code
3. เปิด `index.html` ด้วยส่วนขยาย Live Server (แนะนำ) หรือเปิดไฟล์ผ่านเบราว์เซอร์
4. พิมพ์จุดเริ่มต้น เช่น `เซ็นทรัล ภูเก็ต` หรือกดปุ่มวงกลมเพื่อใช้ GPS
5. เลือกเกณฑ์เส้นทาง แล้วกด **ค้นหาเส้นทางที่ดีที่สุด**

> การใช้ GPS ต้องอนุญาตสิทธิ์ตำแหน่ง และโดยทั่วไปควรเปิดผ่าน localhost (เช่น Live Server) หรือเว็บไซต์ HTTPS

## เทคโนโลยีที่ใช้

- HTML, CSS และ JavaScript — ไม่ต้องติดตั้ง Node.js หรือ build tool
- Leaflet + OpenStreetMap — แสดงแผนที่
- Photon (Komoot) — ค้นหาชื่อสถานที่และพิกัด
- OSRM demo server — คำนวณเส้นทางรถยนต์และทางเลือก
- Google Maps Directions — เปิดแอป/เว็บไซต์นำทางต่อ

## การทำงานของระบบ

- ปลายทางถูกกำหนดไว้ที่ มหาวิทยาลัยสงขลานครินทร์ วิทยาเขตภูเก็ต พิกัดประมาณ 7.89403, 98.35281
- ผู้ใช้เลือกต้นทางด้วยการค้นหาชื่อสถานที่ หรือใช้ GPS
- เลือกเปรียบเทียบตามระยะทางสั้นที่สุดหรือเวลาเดินทางน้อยที่สุด จากเส้นทางที่ OSRM ส่งกลับมา
- คลิกการ์ดเส้นทางเพื่อเน้นเส้นทางนั้นบนแผนที่
- เปิด Google Maps เพื่อใช้นำทางจริงได้

## ข้อจำกัดที่ควรรู้

- เวลาที่แสดงเป็นเวลาประมาณจากข้อมูลเส้นทาง ไม่ใช่เวลาจราจรสด
- เส้นทางเป็นการเดินทางด้วยรถยนต์ (driving)
- จำนวนเส้นทางทางเลือกขึ้นอยู่กับข้อมูลที่บริการ OSRM ส่งกลับมา และเส้นทางที่สั้นที่สุดหมายถึงสั้นที่สุดในตัวเลือกที่ได้รับ ไม่ได้รับประกันว่าเป็นเส้นทางที่สั้นที่สุดทุกเส้นทางที่เป็นไปได้
- Photon, OSRM และ OpenStreetMap เป็นบริการภายนอก เว็บไซต์จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อค้นหาสถานที่ โหลดแผนที่ และคำนวณเส้นทาง
- เซิร์ฟเวอร์สาธิตมีข้อจำกัดด้านการใช้งาน เหมาะกับงานเรียน/ต้นแบบ ไม่ควรใช้เป็นบริการเชิงพาณิชย์ที่มีผู้ใช้จำนวนมากโดยไม่จัดหา API หรือเซิร์ฟเวอร์ของตนเอง
